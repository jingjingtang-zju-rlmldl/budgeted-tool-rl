# Local lookup-policy LoRA adapter

This is an experimental adapter for the controlled lookup environment in this
repository. It was actually trained on the local RTX 5060 Laptop GPU. It is
not an official Qwen model or a general-purpose agent checkpoint.

- Backbone: [Qwen/Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B), revision
  `c1899de289a04d12100db370d81485cdf75e47ca`.
- Data: 300 deterministic oracle episodes, 100 per task family, converted to
  600 assistant-only next-action targets. Forty fact groups have paired budget
  and owner-department goals; 260 distinct train fact groups in total.
- Method: q/v LoRA rank 8, alpha 16, dropout 0.05; frozen BF16 backbone,
  1,146,880 FP32 adapter parameters, one epoch / 75 AdamW steps, seed 42.
- Intended interface: the frozen neutral protocol in `prompts/neutral.txt`,
  with one compact JSON action per model turn and actual tool observations.
- Training and checkpoint provenance: [manifest](training/manifest.json),
  [label/checkpoint audit](training-audit.json), [reproduction](reproduce.md).
- Evaluation and limitations: [experiment summary](summary.json) and
  [Chinese analysis](analysis.zh-CN.md).

The adapter weights are `training/adapter/adapter_model.safetensors`:
SHA-256 `d6e235d92f81787835abaff4f604a28ce11a5753d5b850f6e48a12b64be381a3`.
Base weights are not included. The backbone is published under
[Apache 2.0](https://huggingface.co/Qwen/Qwen3-0.6B/blob/main/LICENSE);
retain the applicable license/attribution when redistributing derivatives.

## Load on another machine

Download the pinned snapshot first; pass the actual local path explicitly.
The PEFT-generated adapter configuration records the original local snapshot
path. That path is provenance, not a portable download location.

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
from peft import PeftModel

snapshot = "path/to/pinned/Qwen3-0.6B/snapshot"
tokenizer = AutoTokenizer.from_pretrained(snapshot, local_files_only=True)
base = AutoModelForCausalLM.from_pretrained(
    snapshot, local_files_only=True, dtype=torch.bfloat16,
    attn_implementation="sdpa",
)
model = PeftModel.from_pretrained(
    base, "results/sft-v1/training/adapter", is_trainable=False,
    local_files_only=True,
).to("cuda").eval()
```

Use `python -m toolrl.sft_eval` for the recorded interface and evaluation;
the training instruction and tool schema matter. The autogenerated
`training/adapter/README.md` is retained unchanged because all checkpoint
files were hashed before test generation. This document supplies its missing
experiment information without rewriting the frozen checkpoint.

## Limits

Training data contains deterministic English lookup questions, short
contexts, a fixed tool schema and at most two required queries. The test
holds out entities, facts and paraphrases within that schema. It does not
establish transfer to unseen tools, error recovery, long planning, noisy
observations, multilingual requests or general agentic RL tasks. Only one
training seed was used. No RL, paid model API or cloud GPU was used.
